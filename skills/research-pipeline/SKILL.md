# Private Research Pipeline

1. Search with the configured private SearXNG backend.
2. Open the original authoritative source whenever possible.
3. Use Hermes browser for normal pages; use a crawler only when breadth/structure requires it.
4. Use Docling for PDFs/documents.
5. Preserve source URLs and dates.
6. Separate sourced facts from inference.
7. Do not send private context to a site merely to improve search relevance.
